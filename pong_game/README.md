🕹️ Pong Game in Python

This is a simple recreation of the classic Pong arcade game built using Python's `turtle` graphics library. 
It’s a beginner-friendly project that demonstrates object-oriented programming (OOP), basic animation, keyboard controls, and collision detection.



🚀 Features

🎮 Two-Player Gameplay
  - Left paddle: Control with `W` (up) and `S` (down)
  - Right paddle: Control with `Up` and `Down` arrow keys
🏓 **Ball Physics**
  - Bounces off top and bottom walls
  - Detects paddle collisions with realistic bounce angles
🧠 **Scoreboard**
  - Automatically updates and displays scores for each player
⏱️ **Smooth Animation**
  - Adjustable ball speed using time delays
🔄 **Ball Reset**
  - Ball resets to center after a point is scored
