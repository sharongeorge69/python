🐢 Turtle Crossing Game

A fun arcade-style crossing game built using Python's `turtle` module. Help the turtle 
cross the road while avoiding oncoming cars. Each successful crossing increases the game's difficulty!

🎮 Game Description

The player controls a turtle that starts at the bottom of the screen and must reach the top withoutgetting hit by cars that move from right
to left. Each time the turtle reaches the finish line, the level increases and cars move faster.

🚀 Features

- Player-controlled turtle with upward movement.
- Randomly generated colored cars.
- Collision detection to end the game when the turtle is hit.
- Increasing car speed with each level.
- Simple, clean, and easy to understand code structure using OOP principles.

 🛠️ Tech Stack

- Python 3
- Turtle Graphics (`turtle` module)
- `random` module
- `time` module
